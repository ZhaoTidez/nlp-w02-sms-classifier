# 第二课学生实践包

版本 W02-SMS-3.0。个人完成。

## 从这里开始

完整解压后，在 Jupyter 中打开 **学生实践手册.ipynb**，从第0节按顺序操作。安装方法、代码和填写位置均在这份手册中。

**学生实践手册.html** 是同一份手册的只读预览，方便不启动 Jupyter 时查看。两者是同一份材料，不需要各做一遍。

## 文件用途

- student_model.py：分类方法，可选择规则、朴素贝叶斯、逻辑回归或自行实现。
- data：训练2525条、开发541条、测试543条。测试文件只有正文与编号，参考标签由教师保留。
- sms_lab.py、reproduce.py、requirements.txt：运行、导出和复现工具，由手册说明如何使用。
- personal：运行后保存结果的文件夹。
